# 📊 Customer Churn Prediction Dashboard

AI-powered machine learning dashboard to predict customer churn risk for telecommunications companies. Built with Streamlit, Scikit-learn, and Plotly.

## 🎯 Features

- **🔮 Predict Churn** - Enter customer details to get personalized churn prediction
- **🏆 Model Performance** - View accuracy (71.5%), precision, recall, and F1-score metrics
- **📈 Analytics** - Explore churn rate (25.10%), contract types, tenure insights
- **📊 Visualizations** - Interactive charts showing churn drivers and customer patterns
- **🎨 Dashboard** - Professional UI with banner and clean navigation

## 🚀 Quick Start
# Install dependencies
pip install -r requirement.txt

# Run dashboard
streamlit run dashboard/app.py
